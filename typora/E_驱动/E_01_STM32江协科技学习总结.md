# 二、`STM32`中断系统

#### 1.中断相关概念

1. 什么是中断？

   - 当主程序执行过程中，外部发生了一个紧急的事件，要求CPU能够暂停当前的任务，转而去执行这个更为紧急的事件，执行完这个紧急事件再回到刚才被打断的地方，继续执行，这个过程叫做中断。

     

2. 中断优先级：多个中断发生同时申请中断，CPU根据中断源的轻重缓急仲裁，优先响应高优先级的中断。

3. 中断嵌套：当一个中断程序正在运行时，又有新的更高优先级的中断源申请中断，CPU再次暂停当前中断程序，转而去处理新的中断程序，处理完成后依次进行返回。

4. 中断源：

   - 对外部中断来说可以是，电平跳变
   - 对定时器来说可以是，定时器溢出
   - 对串口通信来说可以是，接收到了一个数据

5. 中断执行流程：

   1. 中断源发出中断请求
   2. 检查CPU是否允许中断及该中断源是否被屏蔽
   3. 比较中断优先级
   4. 保护现场
   5. 执行中断处理函数（回调函数）
   6. 恢复现场

#### 2.`STM32`的中断

> [!NOTE]
>
> *中断这里可以多看几遍江科大【5-1EXT1】外部中断*

1. `STM32f103`的中断是经过ST公司裁剪过后的的中包括：16个内核中断和68个可屏蔽中断通道包括（`EXTI/ADC/I2C/SPI/WTD/TIMER/RTC`等）
2. 中断的地址/中断向量表：相当于中断跳板
   - 软件程序中的中断函数的地址是由编译器分配、是不固定的，但是中断跳转由于硬件限制只能是跳转到固定的地址执行程序，为了让硬件中断跳转到任意不固定的中断函数位置，在中断向量表中由编译器再加上一条跳转到中断服务函数的代码，这样中断跳转就可以跳转到任意位置。
3. `NVIC`（Nested Vectored Interrupt Controller）嵌套向量中断控制器（叫号系统）
   - 统一分配中断优先级和管理中断（地址越低，优先级越高）
   - 抢占优先级：决定能否抢占/嵌套：高抢占直接打断低抢占；（打断当前中断执行）
   - 响应优先级：当抢占相同时，响应优先级高的先执行；（不能打断但是可以排在中断执行队列前面）

#### 3.`EXTI(Extern Interrupt)`外部中断

- EXTI可以监测指定GPIO口的电平信号，当其指定的GPIO口产生电平变化时，EXTI将立即向NVIC发出中断申请，经过NVIC裁决后即可中断CPU主程序，使CPU执行EXTI对应的中断程序

- 支持的触发方式：上升沿/下降沿/双边沿/软件触发

- 支持的GPIO口：所有GPIO口，但相同的Pin不能同时触发中断：**Pin 脚编号相同 → 共用同一条外部中断线**

  - ```
    EXTI0 → 所有 GPIO 的 Pin0
    
    PA0、PB0、PC0、PD0… 都连到EXTI0；
    
    EXTI1 → 所有 GPIO 的 Pin1
    
    PA1、PB1、PC1… 都连到 EXTI1
    
    AFI0片选，数字相同只有一个能选中，所以数字必须不同
    ```

- 通道数：16个GPIO_Pin，外加PVD输出、RTC闹钟、USB唤醒、以太网唤醒共20个

- 触发响应方式：中断响应/事件响应

  - 中断响应（Interrupt）：必须叫醒 CPU，让 CPU 跑代码来处理
    - 外设信号 → EXTI → NVIC → CPU **暂停当前程序** → **保存现场** → 执行 **ISR 中断服务函数** → 恢复现场 → 回去继续跑
  - 事件响应（Event）：完全硬件自动处理，不通知 CPU、CPU 继续睡觉 / 干别的
    - 外设信号 → EXTI → **事件线（Event Line）** → 直接触发另一个外设（ADC/DMA/ 定时器）
    - 全程不经过 NVIC、不通知 CPU、不跑任何软件代码

外部中断使用场景：想要获取到是外部的很快的突发信号，STM32不知道什么时候来，STM32只能被动读取，信号很快错过读不到；有脉冲STM32立即进入中断处理，没有中断安心做其他的事情；

按键：推荐定时器中断，可以处理按键抖动和松手监测的问题。

为什么外部中断这样使用好？

外部时钟配置：

```c
1.RCC时钟配置(涉及外设的时钟都打开)
2.配置GPIO(复用/电气/io状态)
3.配置AFIO(选择用的IO)   
4.EXTI选择边沿触发方式(上升/下降/双边沿)
  EXTI中断响应/事件响应
5.配置NVIC优先级
    
ctrl +  f 可在keil内搜索参数
ctrl + art + space 可在keil中联想参数
```
