# 51系列单片机概述

## 1.什么是嵌入式？

```c
1.以应用为中心，以计算机为基础，软硬件可以剪裁（适用于系统对功能、可靠性、成本、体积、功耗有严格要求的）专用计算机系统。
2.以解决生活中需求为目标，设计所需产品，如智能家电、电话手表等；在资源受限的情况下，对软硬件进行一些裁剪使其能可靠的完成所需功能。
```

## 2.什么是`CPU,MPU,GPU,NPU,FPU,MCU,SOC`?

| 缩写 |           英文全称           | 核心功能                                                     | 典型应用场景                           |
| :--- | :--------------------------: | :----------------------------------------------------------- | :------------------------------------- |
| CPU  | **Central Processing Unit**  | **中央处理器**。指令处理，数据运算。                         |                                        |
| MPU  |   **Micro processor Unit**   | **微处理器**。单个CPU核心，需外接内存和外设，处理复杂任务    | 计算机（Intel/AMD处理器）              |
| GPU  | **Graphics Processing Unit** | **图形处理器**。并行计算，专用于图形渲染/深度学习            | 游戏显卡（NVIDIA RTX）                 |
| NPU  |  **Neural Processing Unit**  | **神经网络处理器**。专为AI设计的加速器，优化矩阵运算         | 人脸识别（华为昇腾）                   |
| FPU  |   **Floating Point Unit**    | 专用**硬件浮点运算模块**。早期为独立协处理器（如80387），现代多集成于CPU/GPU | 科学计算、3D渲染                       |
| MCU  |  **Micro controller Unit**   | **微控制器**。集成CPU、RAM、ROM、定时器、GPIO等，单一芯片完成控制任务 | All-in-One设计家电、51单片机、汽车电子 |
| SoC  |      **System on Chip**      | **片上系统**。集成CPU+GPU+NPU+RAM+外设，完整计算系统         | 智能手机（骁龙/麒麟芯片）              |

## 4.什么是寄存器?

英文全称：`CPU Register`：CPU内部的高速存储单元（通常由触发器实现），用于暂存运算数据或控制硬件状态。

- 51单片机核心寄存器：
  - `ACC`：Accumulator：累加器，用于算术运算
  - `PSW`：Program Status Word：程序状态标志位
  - `TMOD`：Timer Mode Control：定时器模式控制

## 5.✅位运算：指定位置1和指定位清零

```c
// 定义变量（假设为8位）
unsigned char value = 0xF0; // 二进制: 1111 0000

1.指定位 置一：或等于1左移N位 
//其他位不变，将bit2置1（从0开始计数，第3位）
value |= (1 << 2);  // 结果: 1111  0100 (0xF4)

2.指定位 清零：与等于1左移N位取反
//其他位不变将bit4清零（从0开始计数，第5位） #不考虑代码顺序执行累积
value &= ~(1 << 4); // 结果: 1110 0000 (0xEF)

```
