# i.MX6ULL-定时器中断

---

### 1. PLL、Prescaler、FPD的作用
- **PLL（Phase Locked Loop，锁相环）** ：倍频 
  作用：通过反馈控制将输入时钟倍频到更高频率，为系统提供高频时钟源。

- **Prescaler（预分频器）** ：分频 
  作用：对PLL输出的高频时钟进行分频，生成不同频率的时钟供外设使用，避免外设因时钟过高而无法工作。

- **FPD（Fractional Post Divider，小数分频器）**  
  
  作用：在PFD（Phase Fractional Divider）中实现精细的频率调节，通过小数分频提高频率配置的灵活性（如ARM PLL的PFD0-3）。

---

### 2. i.MX6ULL中的PLL与PFD数量
- **PLL**：共7个  
  - 核心时钟：`ARM_PLL`（专用ARM内核）  
  - 系统时钟：`SYS_PLL`（主PLL，528MHz）  
  - 外设时钟：`USB1_PLL`、`USB2_PLL`、`ENET_PLL`（专用接口）  
  - 视频时钟：`VIDEO_PLL`、`AUDIO_PLL`（多媒体相关）  

- **PFD**：每个PLL最多4个PFD（仅部分PLL支持）  
  例如：`SYS_PLL`包含`PFD0-3`（如PFD0=352MHz，用于总线时钟）。

### 3. ARM PLL配置流程（以提升ARM内核频率为例）

![image-20250813182945193](https://cdn.jsdelivr.net/gh/bingoteng/Photos/Typora/20260718_01-54_3610d0e62269437f1cf44da5a72a90c3.png)

1. **切换时钟源**：  
   将ARM内核时钟临时切换到24MHz晶振（bypass模式），避免PLL重配置时系统不稳定：
   
   ```c
   CCM->CCSR |= CCM_CCSR_ARM_CLK_SEL(1);// 选择osc_clk
   //CCM->CCSR &= ~(1<<8);选择osc_clk
   //CCM->CCSR |= (1<<2);选择step_clk
   ```
   
3. **配置倍频与分频**：  
   设置分频系数（DIV_SELECT）实现目标频率（如528MHz）：
   
   ```c
   unsigned int t ;
       t = CCM_ANALOG->PLL_ARM;
       t &= ~(3<<14);24Mhz
       t |= (1<<13);
       t &= ~(0x7F<<0);//先清0
       t |=(88<<0);//置位 24*88/2=1056
       CCM_ANALOG->PLL_ARM = t; //PLL 1056Mhz
   	CCM->CACRR &= ~(7<<0);
       CCM->CACRR |= (1<<0);	//2分频后 528Mhz
   ```
   
5. **切换回PLL输出**：  
   将ARM时钟源切回PLL：
   ```c
   CCM->CCSR  &= ~(1<<2);  //切回pll1_main_clk
   ```

### 4. EPIT与GPT的工作原理
#### **EPIT（Enhanced Periodic Interrupt Timer）**  
- **工作原理**：  
  1. 加载初始值到计数器（`EPIT_CNR`），递减计数至0时触发中断。  
  2. 支持自动重载（通过`EPIT_LR`），实现精确周期中断。  
  3. 时钟源可选（IPG_CLK或晶振），带预分频器调节频率。  

#### **GPT（General Purpose Timer）**  
- **工作原理**：  
  1. 支持自由运行（从0xFFFF到0x0）或比较模式（匹配`GPT_OCR`触发中断）。  
  2. 可捕获外部信号边沿（输入捕获模式）。  
  3. 时钟源灵活（IPG_CLK、晶振等），分频范围更广。  
  4. 捕获（上升求差）
  
- **应用场景**：  
  测量脉冲宽度、PWM生成、系统时间戳。

#### **关键区别**  
- EPIT专为周期性中断优化（固定周期）；GPT功能更通用（输入捕获/PWM）。  
- EPIT时钟配置更简单，GPT支持自由运行模式。
