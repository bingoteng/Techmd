在 Linux 中解压 `.tar` 文件，最常用的命令是：

```bash
tar -xvf filename.tar
```

参数说明

- `-x` (extract)：解包/解压文件。
- `-v` (verbose)：显示解压过程中的文件列表（可选）。
- `-f` (file)：指定要操作的文件名（**必须放在最后**）。

`.tar` 文件经常与其他压缩算法结合使用，请根据文件后缀选择对应命令：

| 文件后缀               | 解压命令                           | 说明                 |
| ------------------ | ------------------------------ | ------------------ |
| `.tar`             | `tar -xvf file.tar`            | 仅打包，未压缩            |
| `.tar.gz` / `.tgz` | `tar -xzvf file.tar.gz`        | 使用 gzip 压缩 (`-z`)  |
| `.tar.bz2`         | `tar -xjvf file.tar.bz2`       | 使用 bzip2 压缩 (`-j`) |
| `.tar.xz`          | `tar -xJvf file.tar.xz`        | 使用 xz 压缩 (`-J`)    |
| `.tar.zst`         | `tar --zstd -xvf file.tar.zst` | 使用 zstd 压缩         |

> **💡 提示：** 较新版本的 GNU tar（通常 Linux 发行版自带）可以自动识别压缩格式，直接运行 `tar -xvf filename.tar.*` 即可，无需手动指定 `-z`、`-j`
