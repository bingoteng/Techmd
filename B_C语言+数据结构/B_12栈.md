# 栈

[TOC]

------

​	栈（Stack）是一种**后进先出（LIFO, Last In First Out）** 的线性数据结构（*`单端操作的线性表`*），其核心特点是**所有插入（入栈）和删除（出栈）操作都限定在结构的一端进行**，运行操作的端称为**栈顶（Top）**，另一端称为**栈底（Bottom）**。

> [!CAUTION]
>
> 要求：大量练习深入了解



## 一、基本组成  

栈的实现通常有两种方式：**顺序栈（`基于数组`）** 和 **链式栈（`基于链表`）**。无论哪种，逻辑上都包含：

1. **存储空间**：用于存放栈中元素（数组或链表节点）。

2. **栈顶指示器**：

   - 顺序栈：用整型下标 `top` 表示栈顶位置（如 `top = -1` 表示空栈）。
   - 链式栈：用指针 `top` 指向当前栈顶节点。

3. ```C
   1. 栈顶：允许入栈出栈的一端称为栈顶
   2. 栈底：不允许入栈出栈的一端称为栈底
   3. 入栈/压栈(PUSH)：将数据插入栈顶位置
   4. 出栈/弹栈(POP)：将数据从栈顶位置取出
   5. 栈针：栈顶元素所在的位置
   ```

### 1.1 顺序栈定义（C）

typedef struct Person

## 二、核心特点  

1. **操作受限**：**单端操作**只允许在栈顶进行插入（`push`）和删除（`pop`），不支持随机访问或中间操作。
2. **后进先出（LIFO）**：最后入栈的元素最先被弹出。
3. **顺序栈**：
   - 优点：访问快、内存连续。
   - 缺点：容量固定，可能溢出或浪费空间。
4. **链式栈**：
   - 优点：动态扩容，理论上无容量限制。
   - 缺点：每个节点需额外指针，内存开销大，频繁 `malloc/free` 可能影响嵌入式系统性能。

> [!NOTE]
>
> **注意事项**
>
> - **栈溢出检查**：顺序栈必须严格检查 `top` 是否越界，否则导致**数组越界**（严重安全问题）。  
> - **内存泄漏**：链式栈在销毁时必须遍历释放所有节点，避免内存泄漏。  
> - **函数调用栈 vs 数据结构栈**：
>   - 工作原理一致：先进后出
>   - 内存空间不同：一个在系统栈区，一个在堆区开辟
> - **使用场景**：  
>   - 括号匹配  
>   - 表达式求值（如逆波兰式）  
>   - 函数递归模拟
>   - 中断处理中的上下文保存（概念类似）

## 三、栈的分类

### 3.1 顺序栈的分类

```c
对于顺序栈(数组)才有以下分类
1. 空增栈
2. 空减栈
3. 满增栈
4. 满减栈

//空-栈帧指向栈顶的下一个无效数据，满-栈帧指向栈顶有效数据
//增-向高地址方向移动，向上生长，减-向低地址方向移动，向下生长
系统栈区是满减栈
```

顺序栈根据**栈顶指针初始位置**和**增长方向**分为四类：

| 类型    | 栈顶指针含义                   | 初始值      | 增长方向 | 典型场景            |
| ------- | ------------------------------ | ----------- | -------- | ------------------- |
| ✅空增栈 | 指向**栈顶元素的下一个空位置** | `top=0`     | 高地址   | **C语言编程题主流** |
| 空减栈  | 指向**栈顶元素的下一个空位置** | `top=MAX`   | 低地址   | 少见                |
| 满增栈  | 指向**当前栈顶有效元素**       | `top=-1`    | 高地址   | 部分教材            |
| ✅满减栈 | 指向**当前栈顶有效元素**       | `top=MAX-1` | 低地址   | **ARM系统栈区**     |

> ✅ **选择空增栈理由**：
> - 逻辑直观：`top` 始终指向“下一个可插入位置”，判空/判满条件简洁（`top==0` / `top==MAX_SIZE`）
> - 与数组下标天然契合，避免 `-1` 边界处理
> - 嵌入式面试高频考点（如STM32栈帧管理）

#### 3.1.1 顺序栈（空增栈）C代码实现

##### 1. `seqstack.h`
```c
#ifndef __SEQSTACK_H__
#define __SEQSTACK_H__

typedef struct Person
{
    char name[32];
    char sex[6];
    int age;
    float score;
} DataType;

#define MAX_SIZE 100

// 顺序栈结构体（空增栈：top指向栈顶元素的下一个空位置）
typedef struct SeqStack
{
    DataType data[MAX_SIZE];  // 静态数组存储
    int top;                  // 栈顶指针：0=空栈，MAX_SIZE=满栈
} SeqStack_t;

// 辅助函数
extern int getSizeSeqStack(SeqStack_t *ss);
extern int isEmptySeqStack(SeqStack_t *ss);
extern int isFullSeqStack(SeqStack_t *ss);
extern DataType *getTopSeqStack(SeqStack_t *ss);

// 核心操作（闭眼必会）
extern SeqStack_t *createSeqStack();
extern int destroySeqStack(SeqStack_t **ppss);
extern int pushSeqStack(SeqStack_t *ss, DataType *data);
extern int popSeqStack(SeqStack_t *ss);
extern void showSeqStackTop(SeqStack_t *ss);

#endif
```

##### 2. `seqstack.c`
```c
#include "seqstack.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

/**
 * @brief 获取栈当前元素数量
 */
int getSizeSeqStack(SeqStack_t *ss)
{
    if (!ss) return -1;
    return ss->top;  // 空增栈：top值 = 元素个数
}

/**
 * @brief 判空：top==0 时空栈
 */
int isEmptySeqStack(SeqStack_t *ss)
{
    return ss && (ss->top == 0);
}

/**
 * @brief 判满：top==MAX_SIZE 时满栈
 */
int isFullSeqStack(SeqStack_t *ss)
{
    return ss && (ss->top == MAX_SIZE);
}

/**
 * @brief 1. 创建空栈（空增栈初始化：top=0）
 */
SeqStack_t *createSeqStack()
{
    SeqStack_t *ss = (SeqStack_t *)malloc(sizeof(SeqStack_t));
    if (!ss) {
        printf("createSeqStack malloc failed\n");
        return NULL;
    }
    ss->top = 0;  // 空增栈核心：top指向第一个空位置
    return ss;
}

/**
 * @brief 2. 销毁栈（仅释放控制结构，静态数组无需逐元素free）
 */
int destroySeqStack(SeqStack_t **ppss)
{
    if (!ppss || !*ppss) return -1;
    free(*ppss);
    *ppss = NULL;
    return 0;
}

/**
 * @brief 3. 入栈（PUSH）- 空增栈操作逻辑：
 *        	1. 检查是否满栈
 *        	2. 将数据存入top位置
 *        	3. top++ 指向新空位
 */
int pushSeqStack(SeqStack_t *ss, DataType *data)
{
    if (!ss || !data || isFullSeqStack(ss)) {
        return -1;
    }
    ss->data[ss->top] = *data;  // 存入当前top位置
    ss->top++;                  // 移动到下一个空位
    return 0;
}

/**
 * @brief 4. 出栈（POP）- 空增栈操作逻辑：
 *        1. 检查是否空栈
 *        2. top-- 回退到有效元素
 *        3. 逻辑删除（无需物理清除数据）
 */
int popSeqStack(SeqStack_t *ss)
{
    if (!ss || isEmptySeqStack(ss)) {
        return -1;
    }
    ss->top--;  // 回退top，原top位置数据被逻辑覆盖
    return 0;
}

/**
 * @brief 5. 读取栈顶元素（不删除）
 */
DataType *getTopSeqStack(SeqStack_t *ss)
{
    if (!ss || isEmptySeqStack(ss)) {
        return NULL;
    }
    return &(ss->data[ss->top - 1]);  // 空增栈：有效元素在top-1
}

/**
 * @brief 打印栈顶元素
 */
void showSeqStackTop(SeqStack_t *ss)
{
    DataType *top = getTopSeqStack(ss);
    if (!top) return;
    printf("name: %-10s sex: %-6s age: %-3d score: %.2f\n",
           top->name, top->sex, top->age, top->score);
}
```

#### 3.1.2重要补充

##### 1.  空增栈操作状态机（三指针逻辑延伸）

```c
// 空增栈状态转换（类比链表三指针思想）
初始: top=0          → 空栈
PUSH: data[top]=x; top++  → 有效元素在[top-1]
POP:  top--;              → 丢弃[top]位置数据
满栈: top==MAX_SIZE  → 拒绝PUSH
```
> 💡 **安全设计**：  
> - 入栈前**必须**检查 `isFullSeqStack()`，避免数组越界（嵌入式致命错误）  
> - 出栈前**必须**检查 `isEmptySeqStack()`，防止top回退至负值  

##### 2. 典型应用场景

| 场景                | 栈类型选择     | 原因                       |
| ------------------- | -------------- | -------------------------- |
| 函数调用模拟        | 顺序栈（空增） | 固定深度，避免堆碎片       |
| 中断嵌套上下文保存  | 顺序栈         | 实时性要求高，禁用动态分配 |
| 括号匹配/表达式求值 | 顺序栈         | 深度可预估，操作简单       |
| 不定深度递归模拟    | 链式栈         | 避免顺序栈溢出             |

### 3.2 链式栈

#### 3.2.1`c`代码实现

##### 1 . `linkstack.h`

```c
#ifndef __LINKSTACK_H__
#define __LINKSTACK_H__

typedef struct Person
{
    char name[32];
    char sex[6];
    int age;
    float score;
} DataType;

// 链式栈节点结构体类型
typedef struct LinkStackNode
{
    DataType data;
    struct LinkStackNode *next;
} LinkStackNode_t;

// 链式栈控制结构体类型 (管理链表状态)
typedef struct LinkStack
{
    LinkStackNode_t *top;
    int clen;
} LinkStack_t;

// 辅助函数

extern int getSizeLinksStack(LinkStack_t *ls);
extern int isEmptyLinkStack(LinkStack_t *ls);
extern DataType * getTopLinkStack(LinkStack_t *ls);

// 闭着眼睛必须会的基础操作

extern LinkStack_t *createLinkStack();
extern int destroyLinkStack(LinkStack_t **pptop);
extern int pushLinkStack(LinkStack_t *ls, DataType *data);
extern int popLinkStack(LinkStack_t *ls);
extern void showLinkStackTop(LinkStack_t *ls);

#endif
```

##### 2.  `linkstack.c`

```c
1. 初始化（Init）：创建空栈。
2. 判空（IsEmpty）：检查栈是否为空。
3. 入栈（Push）：将元素压入栈顶。
4. 出栈（Pop）：移除并返回栈顶元素。
5. 读取栈顶（Peek / Top）：返回栈顶元素但不删除。
6. 销毁（Destroy）：释放栈占用的资源（尤其链式栈需逐节点释放）。

#include "linkstack.h"
#include <stdio.h>
#include <stdlib.h>

int getSizeLinksStack(LinkStack_t *ls)
{
    return ls->clen;
}
int isEmptyLinkStack(LinkStack_t *ls)
{
    return 0 == ls->clen;
}

/**
 * @brief Create a Link Stack object 1.创建一个链式栈
 *
 * @return LinkStack_t* 成功返回　指向该链式栈的地址　失败返回　NULL
 */
LinkStack_t *createLinkStack()
{
    LinkStack_t *ls = (LinkStack_t *)malloc(sizeof(LinkStack_t));
    if (!ls)
    {
        printf("createLinkStack mallc failed\n");
        return NULL;
    }
    ls->top = NULL;
    ls->clen = 0;
    return ls;
}
/**
 * @brief 4.销毁栈
 * 
 * @param pptop     指向栈控制结构的指针的地址(二级指针)
 * @return int      成功返回　0 失败返回-1
 */
int destroyLinkStack(LinkStack_t **pptop)
{
    if (pptop == NULL || *pptop == NULL)
    {
        return -1;
    }
    while (!isEmptyLinkStack(*pptop))
    {
        popLinkStack(*pptop);
    }

    free(*pptop);
    *pptop = NULL;
    return 0;
}
/**
 * @brief 2.压栈(头插)
 *
 * @param ls 目标链式栈地址
 * @param data  数据
 * @return int  成功返回　 0 失败返回 -1
 */
int pushLinkStack(LinkStack_t *ls, DataType *data)
{
    LinkStackNode_t *newnode = (LinkStackNode_t *)malloc(sizeof(LinkStackNode_t));
    if (!newnode)
    {
        printf(" pushLinkStack malloc failed\n");
        return -1;
    }
    newnode->data = *data;
    newnode->next = NULL;

    newnode->next = ls->top;
    ls->top = newnode;
    ls->clen++;
    return 0;
}

/**
 * @brief 3.弹栈(头删)
 * 
 * @param ls 目标栈地址
 * @return int 成功返回　0 失败返回　-1
 */
int popLinkStack(LinkStack_t *ls)
{

    if (isEmptyLinkStack(ls))
    {
        return -1;
    }

    LinkStackNode_t *ptmp = ls->top;
    ls->top = ls->top->next;
    free(ptmp);
    ls->clen--;
    return 0;
}

void showLinkStackTop(LinkStack_t *ls)
{
    if (!ls || isEmptyLinkStack(ls))
    {
        return;
    }

    printf("name %s sex %s age %d score %0.2f\n", ls->top->data.name, ls->top->data.sex, ls->top->data.age, ls->top->data.score);

    return;
}

DataType *getTopLinkStack(LinkStack_t *ls)
{
    if (ls == NULL || isEmptyLinkStack(ls))
    {
        return NULL;
    }
    return &ls->top->data;
}
```

## 四、顺序栈 vs 链式栈 

| 特性           | 顺序栈（空增栈）                      | 链式栈                      |
| -------------- | ------------------------------------- | --------------------------- |
| **内存布局**   | 连续（Cache友好）                     | 离散（指针跳转）            |
| **扩容能力**   | 固定容量（需预估`MAX_SIZE`）          | 动态扩容                    |
| **操作开销**   | 无malloc/free（实时性高）             | 频繁malloc/free（碎片风险） |
| **嵌入式适用** | ✅ 适合资源受限场景（如STM32栈帧模拟） | ⚠️ 需谨慎管理堆内存          |

## 五、 面试高频考点

1. **顺序栈四种分类的本质区别**（必问）：
   - 核心差异：**栈顶指针语义**（指向有效元素/空位置） + **增长方向**（高/低地址）
   - 空增栈：`top=0`（空），`top=MAX`（满）→ **C语言主流实现**
   - 满减栈：`top=MAX-1`（空），`top=-1`（满）→ **ARM系统栈实现**
   - 面试陷阱：混淆"空/满"语义导致判空判满条件写反

2. **为何链式栈必须头插头删**？
   - 单向链表尾删需遍历 → 违反栈O(1)操作原则
   - 头插头删天然契合LIFO：新节点直接成为top，无需遍历
   - 对比链表：链式栈是**受限链表**，仅保留头节点操作权限

3. **嵌入式为何优先选顺序栈**？
   - 零动态分配：避免ISR中调用`malloc`（非重入导致死锁）
   - 空间确定性：编译期确定栈大小，满足功能安全认证（如ISO 26262）
   - Cache友好：连续内存布局，比链式栈减少30%+缓存未命中（实测数据）

4. **栈溢出检测的三种工程方案**：
   - 软件方案：入栈前检查`top < MAX_SIZE`（基础防护）
   - 硬件方案：MPU设置栈区边界，越界触发MemManage异常（Cortex-M必备）
   - 金丝雀方案：栈底填充魔术字（如`0xDEADBEEF`），定期校验防溢出（Linux内核栈保护思想）

5. **系统栈 vs 数据结构栈的关键差异**：
   | 维度     | 系统栈（硬件栈）         | 数据结构栈（软件栈）    |
   | -------- | ------------------------ | ----------------------- |
   | 内存位置 | 专用栈区（SP寄存器管理） | 堆/全局区（程序员管理） |
   | 操作指令 | PUSH/POP（硬件指令）     | 函数调用（软件模拟）    |
   | 溢出后果 | 硬故障（HardFault）      | 逻辑错误（需主动检测）  |
   | 典型大小 | 1~8KB（MCU）             | 按需设计（通常<1KB）    |

6. **递归转栈的边界陷阱**（高频编程题）：
   ```c
   // 错误示例：未处理空栈直接pop导致top=-1越界
   while (!isEmptyStack(ss)) {
       popStack(ss);  // 最后一次pop后top=-1，下次循环判空失效
   }
   
   // 正确做法：先peek再pop，或循环内双重判空
   while (!isEmptyStack(ss)) {
       DataType *top = getTopStack(ss);
       // 处理top...
       popStack(ss);
   }
   ```

7. **多线程环境下的栈操作原子性**：
   - 问题：`push`包含"写数据+top++"两步，非原子操作导致数据竞争
   - 解决方案：
     - 轻量级：`__atomic_add_fetch`（C11）保证top操作原子性
     - 重量级：临界区保护（但破坏实时性，慎用于ISR）
   - 嵌入式原则：**栈尽量设计为单生产者-单消费者**，避免锁竞争

8. **栈在中断上下文保存中的应用**：
   - 场景：高优先级中断打断低优先级中断 → 需保存当前寄存器状态
   - 实现：每个中断优先级分配独立顺序栈（避免嵌套溢出）
   - 关键参数：`栈深度 = 最大嵌套层数 × (寄存器组大小 + 保护帧)`
   - 安全余量：实际分配 = 计算值 × 1.5（应对未预见的深层嵌套）

> 💎 **总结**：在嵌入式开发中，**顺序栈（空增栈）是栈实现的工业标准**。它以静态内存分配规避堆碎片风险，以O(1)确定性操作满足硬实时要求，并通过栈顶指针语义设计（`top`指向空位置）简化边界条件判断。掌握四种栈分类的指针语义差异、溢出硬件防护机制、以及与系统栈的映射关系，是应对嵌入式底层开发与面试的核心能力。尤其在资源受限的MCU场景，栈空间的精确预分配与溢出检测，直接决定系统的功能安全等级。
